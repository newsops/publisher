# Skills Index

The repository carries the generic workflow skills migrated from `mogak-web` and trims mobile/Firebase-specific procedures.

| Skill                         | Path                                     | Use when                                  |
| ----------------------------- | ---------------------------------------- | ----------------------------------------- |
| Task tracking                 | `task-tracking/SKILL.md`                 | Starting or completing multi-step work    |
| Backlog pipeline              | `backlog-pipeline/SKILL.md`              | Creating or advancing a gated spec        |
| Spec writing                  | `spec-writing-standard/SKILL.md`         | Creating or updating a feature spec       |
| Spec-first development        | `spec-first-development/SKILL.md`        | Before changing behavior, routes, or APIs |
| Spec-code conformance         | `spec-code-conformance/SKILL.md`         | After a spec changes                      |
| Post-implementation checklist | `post-implementation-checklist/SKILL.md` | Before handing off implementation         |
| Code review                   | `code-review/SKILL.md`                   | Reviewing a change set                    |
| Lesson to harness             | `lesson-to-harness/SKILL.md`             | Turning repeated failures into checks     |

UI work should also use `.claude/skills/web-design-guidelines/` and `.claude/skills/vercel-react-best-practices/`.
