# Spec workflow

New pages, routes, content contracts, deployment changes, and admin behaviors require a spec before implementation. The completed platform decision record is `.agents/spec-docs/done/WEB-001-static-public-site-and-admin.md`; new work requires its own gated spec.

Every completion criterion uses a `TC-NN` identifier and has a matching test-plan row. Evidence belongs in the spec gate log, not in chat-only notes.
