# Spec workflow

New pages, routes, content contracts, deployment changes, and admin behaviors require a spec before implementation. The active platform spec is `.agents/spec-docs/draft/WEB-001-static-public-site-and-admin.md` until it passes the repository's approval gates.

Every completion criterion uses a `TC-NN` identifier and has a matching test-plan row. Evidence belongs in the spec gate log, not in chat-only notes.
