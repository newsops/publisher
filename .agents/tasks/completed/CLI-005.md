implicit public release.

## Decisions

- Use only the authenticated, site-scoped Admin API through the existing
  client boundary. The CLI must not bypass authorization, auditing, validation,
  revisions, or provider neutrality.
- Treat configuration, validation, enablement, and public release as distinct
  operations. Google Analytics stays consent-denied until an approved consent
  signal exists.

## Blockers

- None for implementation. Live configuration requires an authenticated CLI
  session; enablement and release retain their separate production safeguards.

Lifecycle implementation, actual regression execution and bundle verification
