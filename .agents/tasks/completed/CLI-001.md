# Agent operations CLI

- **Status**: completed
- **Created**: 2026-09-13
- **Branch**: main
- **Scope**: packages/ops-cli, apps/admin API automation routes, docs, harness

## Objective

Complete the provider-neutral `publisher` command contract so an autonomous
operator can inspect state, request idempotent publication, follow an
operation, and stop cleanly at a human-only authorization boundary.

## Plan

- [x] TC-01: Verify `doctor` returns a redacted, versioned non-interactive
      configuration result and documented exit code.
- [x] TC-02: Verify authenticated `status` and `operation get` expose stable
      pending, terminal, and retryable operation state only.
- [x] TC-03: Verify repeat publish requests with one idempotency key preserve
      one operation identity.
- [x] TC-04: Verify an authority-required publish never issues a mutation.
- [x] TC-05: Verify device authorization discovery, interval behavior, and
      token redaction without token persistence.
- [x] TC-06: Run CLI contracts and full credential-free regression gates.
- [x] TC-07: Verify the canonical product plan preserves agent-first and
      human-only authority statements.

## Progress

### 2026-09-13

- Recreated the required active record after the implementation gate's prior
  record was absent from the repository.
- GATE-VERIFY found that the existing CLI fixture covers only TC-01 and TC-04;
  remaining contracts require implementation and regression coverage.
- Completed a local API/OIDC fixture suite for doctor, state, idempotent
  publish, authority boundaries, and token-redacted device authorization.
- Full credential-free verification passed: `pnpm typecheck`, `pnpm test`,
  `pnpm build`, and `pnpm harness:scan` (133 harness tests and six scans).

## Decisions

- The CLI remains a provider-neutral authenticated admin API client. It does
  not connect directly to PostgreSQL, object storage, or a host control plane.

## Blockers

- None.

## Result

The provider-neutral CLI exposes versioned JSON state and idempotent publish
contracts, and it stops at user-only authority boundaries without exposing or
persisting device-flow tokens.
