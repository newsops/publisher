# WEB-005 Static X post embeds through oEmbed

- **Status**: completed
- **Created**: 2026-09-15

## Objective

Resolve canonical X post URLs through the official X oEmbed endpoint during authenticated authoring, persist a safe static representation, and render it without reader-time third-party dependencies.

## Plan

- [x] Implement resolver validation, timeout and malicious-response safety (TC-01).

- [x] Add equivalent authenticated API, admin UI, client and CLI operation (TC-03).
- [x] Publish the Pro 20X article through the new oEmbed operation with an approved official image.
- [x] Verify desktop/mobile browser rendering and close the final gate (TC-05).

## Decisions

- Fetch oEmbed only at authoring time, never at public-reader time.
- Persist parsed public text and canonical source URL, never provider HTML, scripts or iframes.
