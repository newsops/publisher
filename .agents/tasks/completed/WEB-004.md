## Decisions

- Keep one production publication pipeline and restore its semantic renderer instead of deploying the React fixture as a second source.
- Preserve the selected-theme boundary so future visual changes do not regenerate article HTML.
- Load the stable selected-theme CSS route during HTML parsing instead of attaching the stylesheet after first paint.
