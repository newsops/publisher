# CLI-002: Archive Restore and Static Release

- **Status**: completed
- **Created**: 2026-09-13
- **Branch**: feat/admin-client
- **Scope**: packages/content, packages/ops-cli, apps/admin, packages/persistence, scripts/deploy, docs

## Objective

Provide a provider-neutral, agent-first CLI/API workflow that restores a
private archive without checking it into the repository, protects the generic
starter fixture with revision and idempotency rules, and hands a verified static
release directory to the selected host CLI.

## Decisions

  to PostgreSQL or a provider control plane.
- The archive remains outside the public repository; all committed fixtures are
  generic.
